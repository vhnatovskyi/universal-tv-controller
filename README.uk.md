# BRAVIA Remote

[English](README.md)

Пульт .NET MAUI для Sony BRAVIA на Windows та iPhone. Застосунок підключається до телевізора в локальній мережі через Sony Simple IP Control (TCP 20060). Перші перевірки виконані на BRAVIA 3.

## Встановлення на Windows

1. Відкрий [GitHub Releases](https://github.com/vhnatovskyi/tv-controller/releases/latest) і завантаж `BraviaRemote-Setup-X.Y.Z.exe` для Windows x64.
2. Запусти інсталятор, а потім відкрий **BRAVIA Remote** з меню «Пуск». Інсталятор працює для поточного користувача. Для видалення відкрий **Налаштування → Програми → Інстальовані програми**.
3. Для портативного запуску розпакуй увесь архів `BraviaRemote-X.Y.Z-Windows-x64.zip` і запусти `BraviaRemote.exe`.

## Користування пультом

1. Під’єднай телевізор і ПК або iPhone до однієї домашньої мережі. Увімкни **Просте управління IP** на телевізорі. На iPhone дозволь доступ до локальної мережі, коли з’явиться запит.
2. Додай профіль, обери **IP** і введи назву та IPv4-адресу телевізора. У формі видно, чи доступний спосіб підключення. Пряме керування через Bluetooth наразі недоступне. Перший профіль стає профілем за замовчуванням. Щоб змінити його, відкрий **☰ → Налаштування**, обери інший профіль і натисни **За замовчуванням**.
3. Індикатор гучності оновлюється приблизно кожні три секунди, поки відкритий пульт. **Перевірити з’єднання** показує результат у тимчасовому сповіщенні.
4. У **Налаштуваннях** обери профіль телевізора, натисни **Спарувати з Google TV** і введи шестисимвольний код з екрана телевізора. Потім відкрий **Налаштувати швидкі кнопки**, обери YouTube, Netflix або Kyivstar TV та збережи кнопку. Для одного профілю доступно до шести кнопок. Для запуску застосунок має бути встановлений на телевізорі.
5. Інтерфейс використовує мову системи, а для непідтримуваних мов — англійську. Змінити її можна в **Налаштування → Мова застосунку**.

Увімкнення з режиму очікування залежить від параметра «Віддалений пуск» і доступності Simple IP Control у цьому режимі.

## Збірка та релізи

Дивись [інструкцію з розробки та релізів](docs/DEVELOPMENT.uk.md). Для встановлення на iPhone потрібен Mac із Xcode та підпис для фізичного пристрою.

Під час запуску застосунок перевіряє GitHub Releases. Для ручної перевірки відкрий **☰ → Оновлення**. Якщо доступна новіша стабільна версія, з’явиться банер із посиланням на реліз. Завантаження й встановлення оновлень виконуються вручну.

- [Sony Simple IP Control](https://pro-bravia.sony.net/remote-display-control/simple-ip-control/)
- [Pair to Mac для розробки на iOS](https://learn.microsoft.com/dotnet/maui/ios/pair-to-mac?view=net-maui-10.0)
- [Apple Personal Team](https://developer.apple.com/help/account/basics/about-your-developer-account)
