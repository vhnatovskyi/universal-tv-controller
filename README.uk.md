# Universal TV Controller

[English](README.md)

Пульт .NET MAUI для Sony BRAVIA на Windows та iPhone. Використовує спарування Google TV у домашній мережі.

## Встановлення на Windows

Завантаж `UniversalTvController-Setup-X.Y.Z.exe` з [GitHub Releases](https://github.com/vhnatovskyi/universal-tv-controller/releases/latest). Інсталятор додає застосунок у меню «Пуск» і підтримує видалення через налаштування Windows. Також доступний портативний ZIP.

## Підключення телевізора

1. Під’єднай телевізор і ПК або iPhone до однієї домашньої мережі.
2. Додай профіль, обери телевізор зі знайдених пристроїв і натисни **Спарувати та зберегти**. Назва ТВ заповниться автоматично, її можна змінити.
3. Введи шестисимвольний код з екрана телевізора. Профіль збережеться після успішного спарування.
4. У **Налаштуваннях** можна вибрати профіль за замовчуванням, повторити спарування та додати швидкі кнопки YouTube, Netflix і Kyivstar TV.

Версія 0.3.4 скидає профілі попередніх версій і дані їхнього спарування. Після оновлення створи новий профіль.

Гучність та індикатор активного застосунку оновлюються через Google TV, поки відкритий пульт. Для невідомого застосунку показується загальна іконка, а в підказці — назва пакета. Швидка кнопка повідомляє про успіх після підтвердження потрібного активного застосунку телевізором.

Мова інтерфейсу визначається мовою системи, для непідтримуваних мов використовується англійська. У налаштуваннях доступний ручний вибір. Розділ **Оновлення** показує релізи та посилання для ручного встановлення.

Для голосового введення відкрий пошук або текстове поле на ТВ, натисни мікрофон, скажи коротку фразу та перевір текст перед надсиланням. На Windows використовується встановлений розпізнавач для вибраної мови. На iPhone потрібні дозволи на мікрофон і розпізнавання мовлення. Шестерня відкриває налаштування телевізора.

## Розробка

Дивись [інструкцію з розробки](docs/DEVELOPMENT.uk.md). Для iPhone потрібен Mac із Xcode та підпис Apple для фізичного пристрою.

- [Опис протоколу Google TV Remote](https://github.com/sonalder-darlene/libremote-android-tv/blob/main/PROTOCOL.md)
- [Pair to Mac](https://learn.microsoft.com/dotnet/maui/ios/pair-to-mac?view=net-maui-10.0)

Windows v0.4.3 використовує спільні .NET 10 (x64) та Windows App Runtime 1.7 (x64). Інсталятор перевіряє їх і завантажує відсутні компоненти Microsoft; встановлення .NET може запитати дозвіл адміністратора. Для ZIP потрібні ті самі залежності (запустіть Install-Dependencies.ps1 через Windows PowerShell). Інсталятор стискає файли застосунку алгоритмом Windows LZX на підтримуваних дисках NTFS. Runtime займають додаткове місце та використовуються спільно з іншими програмами.
